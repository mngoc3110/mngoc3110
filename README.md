  *Trinh Huy Hoang, Tran Van Tuan, **Nguyen Le Minh Ngoc**, Nguyen Duong Quoc Bao, Le Hong Thuy Vu*  
  * **Journal:** *HCMUE Journal of Science (Natural Sciences and Technology)*, Vol. 22, No. 11 (2025), pp. 1993–2005.  
  * **DOI:** [`10.54607/hcmue.js.22.11.5018(2025)`](https://doi.org/10.54607/hcmue.js.22.11.5018(2025))  
  * **Highlights:** Proposed an optimized Encoder-only U-Net architecture with a dedicated classification head for lung cancer diagnosis on CT scans (IQ-OTH/NCCD dataset), achieving superior computational efficiency and classification accuracy over ViT, ResNet-50, and VGG-16.
